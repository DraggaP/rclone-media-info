Rclone Media privacy information

Updated 18 October 2026.

Rclone Media is a personal Google Drive integration maintained by DraggaP. It is used by its owner to manage files on Google Drive and a private server.

Google Drive access

The integration requests Google Drive permission so rclone can list, read, upload, update, move and delete files when instructed by the owner. Google supplies authorization tokens; the app does not receive the owner's Google password.

Use and storage

File contents and metadata are processed as needed to carry out the owner's file-management commands. Files may be stored on the owner's server and Google Drive. Authorization tokens are stored in the server's private rclone configuration. This website does not contain those tokens or files.

Sharing and retention

The integration does not sell Google user data or use it for advertising. Data is transferred between the owner's server and Google services to perform the requested operations. Files and local caches are retained according to the owner's configuration and file-management actions. Google handles data on its services under its own policies.

Access controls

The owner can revoke access through Google Account connections and remove saved credentials from the server. Revoking access does not automatically delete files already stored on the server or Google Drive.

This website

This static site has no analytics scripts, advertising, forms or application cookies. Its hosting provider may process ordinary web access logs under its own privacy policy.

Contact

The maintainer's public profile is github.com/DraggaP.
